隐私政策

Polyglot - 智能网页翻译

本隐私政策说明 Polyglot 浏览器扩展（以下简称"本扩展"）如何收集、使用和存储您的数据。使用本扩展即表示您同意本政策。

1. 我们收集哪些数据

  • 网页文本内容：为实现翻译功能，本扩展会读取当前网页中的可见文本节点，并发送至翻译服务。
  • 用户输入内容：当您使用输入翻译功能时，您在输入框中键入的文字会被读取并发送至翻译服务。
  • 划词选中内容：您在网页上选中的文本会被读取并发送至翻译服务。
  • API 配置信息：您提供的腾讯云 SecretId、SecretKey 及区域设置存储在浏览器本地存储中。
  • 偏好设置：目标语言、翻译模式、黑名单等设置存储在浏览器本地。

2. 数据如何被使用

  • 网页文本仅用于调用腾讯云机器翻译（TMT）API 以生成翻译结果。
  • 翻译结果会缓存在您本地的浏览器存储中（内存和 IndexedDB），缓存有效期为 7 天，用于加速重复内容的翻译。
  • 您的 API 密钥仅用于签署腾讯云 API 请求，不会发送至除腾讯云 API 端点外的任何服务器。
  • 本扩展不会将任何数据上传至开发者服务器，所有数据仅存储在您的浏览器本地。

3. 第三方服务

  • 本扩展使用腾讯云机器翻译（TMT）服务进行文本翻译和语言检测。
  • 发送至腾讯云的文本数据受腾讯云隐私政策约束。
  • API 请求通过 HTTPS 加密传输。
  • 除腾讯云 TMT API 外，本扩展不与任何其他第三方服务通信。

4. 数据存储与安全

  • API 密钥和偏好设置通过 Chrome/Firefox/Edge 的 storage.local API 加密存储。
  • 翻译缓存存储在浏览器本地 IndexedDB 和内存中，7 天后自动过期。
  • 本扩展不会将任何数据上传至开发者控制的服务器。
  • 您可以通过选项页面随时清除翻译缓存，或通过浏览器设置清除扩展存储数据。

5. 用户权利

  • 您可以随时在选项页面查看和修改 API 配置及偏好设置。
  • 您可以随时卸载本扩展，卸载后所有本地存储数据将被清除。
  • 您可以随时通过在选项页面删除 API 密钥来停止数据发送。

6. 免责声明

本扩展为开源软件，按"原样"提供，不提供任何明示或暗示的保证。翻译质量取决于腾讯云 TMT 服务。开发者对因使用本扩展而产生的任何翻译错误、数据丢失或费用不承担责任。

7. 联系我们

如对本隐私政策有任何疑问，请在项目的 GitHub Issues 页面提交反馈。

Privacy Policy

Polyglot - Smart Web Translator

This Privacy Policy explains how the Polyglot browser extension ("the Extension") collects, uses, and stores your data. By using the Extension, you agree to this policy.

1. What Data We Collect

  • Webpage text content: To provide translation, the Extension reads visible text nodes from the current webpage and sends them to a translation service.
  • User input content: When using the input translation feature, text you type into input fields is read and sent to the translation service.
  • Selected text: Text you highlight on a webpage is read and sent to the translation service.
  • API credentials: Your Tencent Cloud SecretId, SecretKey, and region settings are stored in your browser's local storage.
  • Preferences: Target language, translation mode, blacklist, and other settings are stored locally in your browser.

2. How Data Is Used

  • Webpage text is used solely to call the Tencent Cloud Machine Translation (TMT) API to generate translations.
  • Translation results are cached locally in your browser (memory and IndexedDB) with a 7-day expiration to speed up repeated translations.
  • Your API credentials are used only to sign Tencent Cloud API requests and are never sent to any server other than the Tencent Cloud API endpoint.
  • The Extension does not upload any data to developer-controlled servers. All data is stored exclusively in your browser.

3. Third-Party Services

  • The Extension uses Tencent Cloud Machine Translation (TMT) for text translation and language detection.
  • Text data sent to Tencent Cloud is governed by the Tencent Cloud Privacy Policy.
  • API requests are transmitted over encrypted HTTPS connections.
  • Apart from the Tencent Cloud TMT API, the Extension does not communicate with any other third-party services.

4. Data Storage & Security

  • API credentials and preferences are stored using the browser's storage.local API.
  • Translation cache is stored in the browser's local IndexedDB and memory, automatically expiring after 7 days.
  • The Extension does not upload any data to developer-controlled servers.
  • You can clear the translation cache at any time from the Options page, or clear extension storage via your browser settings.

5. User Rights

  • You can view and modify your API configuration and preferences at any time on the Options page.
  • You can uninstall the Extension at any time, which will remove all locally stored data.
  • You can stop data transmission at any time by removing your API credentials from the Options page.

6. Disclaimer

The Extension is open-source software provided "as is" without warranty of any kind, express or implied. Translation quality depends on the Tencent Cloud TMT service. The developer is not responsible for any translation errors, data loss, or charges incurred through use of the Extension.

7. Contact Us

If you have any questions about this Privacy Policy, please submit feedback via the project's GitHub Issues page.
